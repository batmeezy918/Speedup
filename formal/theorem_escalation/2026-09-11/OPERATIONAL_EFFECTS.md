# Operational Effects Contract

Theorem promotion is monotone and evidence-bound.

```text
CANDIDATE
   -> FORMAL_PARTIAL
   -> VERIFIED
   -> DERIVED_OPERATIONAL
   -> CONCRETE_INSTANTIATION
```

No stage may be skipped.

## Mapping

### SCQ-001 — Greatest Stable Constitutional Quotient
Provides the canonical state-identification relation for the stable observable/dynamical domain.

### SCQ-002 — Unique Quotient Dynamics
Provides a well-defined quotient transition `Tbar` satisfying `pi ∘ T = Tbar ∘ pi`.

### SCQ-003 — Exact Recursive Projection
Provides exact finite-horizon projected trajectories.

### SCQ-004 — Universal Observable Factorization
Allows any declared observable constant on the stable quotient fibres to descend uniquely.

### SCQ-005 — Bidirectional Constitutional Closure
Binds constitution preservation to quotient-class preservation/admissibility within the declared model.

### SCQ-006 — Reconstruction
Allows representative recovery only when a section/reconstruction witness exists.

### SCQ-007 — TEL
Defines canonical quotient-preserving representative replacement. This is a semantic operator, not a physical teleportation claim.

### SCQ-008 — Directed TEL
Adds an explicitly admissible quotient-level target transformation `G_phi`.

### SCQ-009 — Bounded Infinity
Extends the semantic construction to infinite state spaces with bounded quotient cardinality under its stated assumptions.

## Speedup boundary

Even a fully verified quotient theorem establishes semantic reduction/equivalence. It does **not** establish a runtime or hardware speedup. Performance promotion requires an independent reproducible benchmark and the repository's PCSS gates.
