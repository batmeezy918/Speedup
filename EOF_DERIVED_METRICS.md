# EOF Derived Metrics Upgrade

The MASQ/EOF benchmark now defines the intended metric upgrade: execution-derived observations must replace hard-coded placeholder values for ΔC, Ω, and Ξ.

## Measurement contract

- ΔC: derived from declared raw state feature count versus observable quotient dimension.
- Ω: derived from observed multi-dimensional mutation/co-occurrence behavior in executed cases.
- Ξ: derived from observed mutation/sensitivity coverage, not a fixed constant.
- RIF: passed observable projections divided by completed cases.
- Domain span: unique executed states, projections, and decisions.

## Evidence boundary

These metrics describe the declared local benchmark domain only. They do not establish global minimality, production payment-network equivalence, or network certification.

Claim strength remains bounded by evidence strength.
