# Operational permissions

Each GREEN kernel fact is a permission, not a press release.
If a lemma is not in the left column, no scheduler or publisher
may treat it as a new permission.

| Lemma / module | A machine may | A machine may not |
|---|---|---|
| T0 field preservation, `wipeNs` | reject an operator that breaks namespace/version/provenance/Ω | treat rejection as a speedup |
| `TBar_sound`, `admission_iff_TBar` | execute the reduced operator on Q when an intertwiner exists | claim wall-clock dropped |
| `nrebbi_el` / `admissible_iterate` | iterate the reduced operator n times | treat n as a complexity proof for silicon |
| `admissible_compose` | pipeline safe operators | compose unofficial coco-equivalent scripts into a SOTA claim |
| `exists_reconstruct` (conditional) | rebuild a representative when a section is supplied | claim every quotient is invertible |
| GEMM `fullWork` / `workRatio_outer` | report a Nat work ratio | print that ratio as measured speedup |
| `measured_hundredths_neq_work_ratio_times_100` | refuse the identification work-ratio = runtime | — |
| `publish_requires_all_gates` | refuse publication when any bit is false | flip a bit by moving a folder |
| `lean_false_not_publishable` | keep `lean: false` packets out of VERIFIED | store them under `verified/` |
| OIC `empty_corpus_always_boundary` | emit a structured miss | derive an arbitrary proposition from an empty attic |
| OIC `elevation_requires_provenance` | demand a parent hash before class change | elevate by narrative |
| Graph500 official BFS logs | cite TEPS as a baseline | cite them as a twin speedup |
| cocoex 360 GATE_FAILURE | publish a NEGATIVE result | call the architecture “COCO-verified” |
| SIM2XR witnesses, error 0.0 | report STRONG_LOCAL sector ratios on Termux aarch64 | call them universal SIM2XR or Lean-proven timing |

Counting `refl` / `symm` / `trans` does not add rows to this table.
