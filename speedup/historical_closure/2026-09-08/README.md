# Historical speedup closure — target execution

This directory contains the 2026-09-08 target-device closure of the first eight literal speedup records.

- **VALIDATED:** SIM2XR shared-prefix — median **17.544277x** verified runtime speedup across 7 repeats, exact output/hash equivalence, canonical parameters preserved.
- **BLOCKED:** GS254/RIMS — 5 paired executions completed; semantic E_eq witness gate returned `INSTRUMENTATION_MISSING`, so the 18.5334x claim was not elevated.
- **NOT VALIDATED:** Omega v6.3 — two complete 96-bit paired trials produced ratios 0.3208x and ~6.009x; correct factors, but no stable 2.60x speedup.
- **PENDING:** Omega-BFGS v5, Sparse 1M, Omega v7 aggregate, Haradax alpha — canonical executable runners/parameters were not recovered for exact target replay.
- **SUPPORTING:** ChronoFold Quant/CFArena — retained as validation infrastructure, not speedup claims.

The closure intentionally distinguishes structural work reduction, projection/objective ratios, measured runtime, and universal performance. No universal speedup, HPC dominance, quantum advantage, or cryptographic break is asserted.
